# Agent Spend Guard (Saifuro Core Logic Simulation)

An open-source, sandbox architecture simulating an authorization and mandate-enforcement layer for AI agent transaction pipelines. Built to replicate the architectural goals of Saifuro's append-only policy engine.

## 🚀 Shipped Product Capabilities
- **Synchronous Policy Evaluation:** Validates transaction category, limits, and frequency arrays prior to payment execution.
- **Append-Only Decision Log:** Automatically commits every signed verdict (approvals and denials) to an immutable ledger for month-end compliance auditing.
- **Velocity Tracking:** Measures micro-transaction frequency spikes to prevent agent loops and programmatic fraud.
